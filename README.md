# Interacciones Basicas con Archivos de CSV, JSON y EXCEL
Lo que se realizara dentro de esta practica será generar un archivo Notebook de Python que contenga codigo fuente de varios ejercicios aplicados a tres fuentes:
- Se debe leer el archivo de cada uno y guardarlo en una lista
- Cada archivo debe mostrar las lineas principales y finales para ubicar cada area
- Se deben seleccionar 2 a 4 columnas que se extraigan para hacer un nuevo archivo
